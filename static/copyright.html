© 2026 Stock Manager

A lightweight inventory management system for shops and warehouses.
Built with FastAPI, SQLite (Supabase), and Vercel.

App Features

  • Dashboard — KPIs, stock value, profit, low-stock count
  • Items — Add/edit items with SKU, barcode, price, cost, location, supplier, batch, expiry
  • Movements — Full stock history with user attribution
  • Warehouses — Per-location stock value overview
  • Alerts — Low stock and expiry warnings
  • Prices — Cost + sell price, auto 5% markup, price history
  • POS / Checkout — Scan barcodes, build bills, M-Pesa payment prompt
  • Suppliers — Add suppliers, view purchase orders
  • Purchases — Create POs, receive stock
  • Sales — Record sales, reduce stock, track profitability
  • Users — Admin: add/edit/delete users with location limits
